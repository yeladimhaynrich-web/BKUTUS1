# 📱 Bluetooth File Transfer App (העברת קבצים בבלוטוס) & APK Auto-Builder

פרויקט מבוסס Android Native (Kotlin) להעברת קבצים בין שני מכשירים באמצעות בלוטוס בלבד, כולל עיון בתיקיות המכשיר המקביל והורדת קבצים שנבחרו.

---

## 🚀 הוראות להעלאת תקיית AAA ל-GitHub וקמפול אוטומטי של APK

כדי לקמפל את הפרויקט הזה לקובץ **APK (בתוך קובץ ZIP)** באופן אוטומטי ללא התקנת Android Studio במחשב:

### שלב 1: העלאת הקבצים ל-GitHub
1. צור מאגר (Repository) חדש ב-GitHub (לדוגמה: `bluetooth-file-transfer`).
2. העלה **רק את תוכן תקיית `AAA`** בלבד לרשת הראשית (`main` או `master`) של המאגר ב-GitHub.
3. הקפד שהתיקיות `.github/workflows/build-apk.yml`, `app/`, `build.gradle` ו-`settings.gradle` יימצאו בשורש (Root) של המאגר.

### שלב 2: קמפול אוטומטי (GitHub Actions)
1. ברגע שהעלית את הקבצים ל-GitHub, ייפתח באופן אוטומטי תהליך לבניית ה-APK בלשונית **Actions** ב-GitHub.
2. תהליך הבנייה נמשך כ-2–3 דקות.
3. בסיום התהליך, תחת **Artifacts**, תמצא קובץ **ZIP** בשם `BluetoothTransferApp-APK-ZIP`.

### שלב 3: הורדה והתקנה במכשיר
1. הורד את קובץ ה-ZIP מה-Actions ב-GitHub.
2. חלץ את ה-ZIP ותמצא בתוכו את הקובץ `BluetoothFileTransfer-debug.apk`.
3. העבר את קובץ ה-APK למכשיר האנדרואיד שלך והתקן אותו!

---

## 🛠️ תכונות האפליקציה (Features)
- **סריקת מכשירים בבלוטוס**: איתור מכשירים בסביבה וחיבור Bluetooth RFCOMM.
- **בקשת אישור גישה**: בקשת רשות מהמכשיר השני לקריאת התיקיות שלו.
- **עיון מרחוק בתיקיות**: דפדפן תיקיות מרוחק שאינו דורש חיבור לאינטרנט או Wi-Fi.
- **בחירת קבצים מרובה**: בחירה מרובה של קבצים ותמונות והעברתם בבלוטוס ישירות לתיקיית `Downloads/BluetoothTransferred`.
- **מצב מארח (Host Mode)**: מאפשר למכשיר שלך לשתף תיקיות ספציפיות בבטחה.
